# USDA Validation Study
## Summary
This project is aimed at validating RT-QuIC and Nano-QuIC for post- and ante-mortem testing of white-tail deer. This is a longitudinal study, with sampling efforts every 3 months. 
### Ante-mortem samples:
-   Oral swabs
-   Nasal swabs
-   Rectoanalmucosa-associated lymph tissue (RAMALT)
-   Whole blood
-   Plasma
-   Serum
-   Ear punches
-   Feces
### Post-mortem samples:
-   Obex
-   RAMALT
-   RPLN

## Airtable Integration
This project uses both a Python client, **[pyAirtable](https://pyairtable.readthedocs.io/en/stable/)**, and an R client, **[airtabler](https://github.com/bergant/airtabler)**, to interface with the Airtable API. A user must have an API key with sufficient permission in both the `.env` and `.Renviron` files. It is imperative that the envrionment variable name in `.Renviron` is `AIRTABLE_API_KEY`. The `airtabler` functions will only work with that name.

## Data Workflow
The data pipeline has 6 steps:
1. Add raw Excel files into the appropriate sub-directory in the `raw/` folder.
2. Extract the raw data into usable tidy-data formats.
3. Calculate relevant kinetic metrics from the raw data.
4. Save the data into compressed parquet files in the `data/` folder.
5. Read the parquet files and update Airtable with results.
6. Analyze results by pulling data from Airtable (Airtable has relevant metadata).

### Adding Raw Files
MARS-exported Excel files should be added into the `raw/` folder. The target sub-folder will depend on the sample type. If a sample has a MNPRO process ID, it likely will go in the processedSamples folder.

### Extracting Raw Data
This project utilizes `renv`. Please ensure you are working within the virtual environment to guarantee consistent results between users. This project uses the updated development version 3.0.4 of **[quicR](https://github.com/gage1145/quicR/releases/tag/v3.0.4)**. Please make sure you are using this version. `renv` should ensure this.

Running `curate.R` will extract raw data, generate calculations, and provide basic summaries. These results are then saved in the `data/` folder as parquet files. These files are excluded intentionally from the repo since they can become very big and can be generated by the user upon execution of `curate.R`.

Within the R console:
```R
# If the virtual environment hasn't been activated.
renv::activate()
# Run the curation script
source("curate.R")
```

### Updating Airtable
Updating Airtable is done using the Python client, so the user must work within a Python virtual environment.
```bash
# Initialize the virtual environment
python -m venv .venv

# Activate the virtual environment
.venv\Scripts\activate # Windows
source .venv\bin\activate # Linux/MacOS

pip install -r requirements.txt
```

Once the virtual environment has been created and the user will need to make a `.env` file in the home directory.
```bash
type nul > .env # Windows
touch .env # Linux/MacOS
```
In the `.env` file, add the `KEY` variable with the Airtable API key.
```python
KEY=airtableapikey
```
Now Airtable can be updated with the data that was generated from the R script.
```bash
python airtable/update_results.py
```

### Analyzing Data from Airtable
Analysis is performed in R, and thus generated data and metadata is pulled from Airtable using the R client. Again, make sure the R virtual environment is activated before performing analyses.

Here is an example script for getting data from Airtable:
```R
library(airtabler)

# Base ID
APP <- "app7KsgYl2jhOnYg7"

# Generalized function for making Airtable query formulas.
get_formula <- function(id, values, operator="OR") {
  make_string <- function(value) sprintf("%s({%s} = %s", operator, id, value)
  sapply(values, make_string) |>
    paste(collapse=",") |>
    paste0(strrep(")", length(values)), collapse="")
}

# Get the necessary tables and filter for desired samples.
tables <- airtable(APP, c("animals", "results"))
animals <- tables$animals$select_all()
results <- tables$results$select_all(
  filterByFormula = get_formula(
    "sample_type", c("'MNPRO oral swab'", "'NADC oral swab'")
  )
)
```
